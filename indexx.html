About the project

The 8085 Microprocessor

The Intel 8085 is an 8-bit microprocessor introduced in 1976. It remains one of the most widely used teaching processors because of its clean architecture and simple instruction set.

What is the 8085?

8-bit NMOS microprocessor. 8-bit data bus, 16-bit address bus (64 KB), 8-bit ALU, six general-purpose 8-bit registers (B,C,D,E,H,L), accumulator (A), flag register, stack pointer and program counter. Runs at 3.07 MHz. Supports memory and I/O addressing.

What is GNUSim8085?

Free, open-source graphical simulator and assembler for the Intel 8085 microprocessor. Widely used in engineering colleges for writing, assembling and step-debugging 8085 assembly programs on a PC.

About this website

An independent educational browser-based emulator inspired by GNUSim8085. It is not the GNUSim8085 desktop application. Supports a documented subset of valid 8085 instructions.

Reference Material

Everything you need for the lab, viva and exams.

8085 Architecture

  • 8-bit data bus, 16-bit address bus (64 KB).
  • ALU, Accumulator, 6 general registers.
  • Flags: S, Z, AC, P, CY.
  • PC and SP registers.
  • Control unit with IR and decoder.
  • Interrupts: TRAP, RST 7.5/6.5/5.5, INTR.

Registers & Pairs

  • 8-bit: A, B, C, D, E, H, L.
  • Pairs: BC, DE, HL (HL = memory pointer).
  • SP: 16-bit stack pointer.
  • PC: 16-bit program counter.
  • Flags: S, Z, AC, P, CY.

Instruction Categories

  • Data transfer: MOV, MVI, LXI, LDA, STA, LHLD, SHLD.
  • Arithmetic: ADD, ADI, SUB, SUI, INR, DCR, INX, DCX.
  • Logical: ANA, ORA, XRA, CMA, CMP, CPI.
  • Branch: JMP, JZ, JNZ, JC, JNC, CALL, RET.
  • Stack: PUSH, POP.
  • Control: NOP, HLT.

Addressing Modes

  • Immediate: MVI A, 05H
  • Register: MOV A, B
  • Direct: LDA 2050H
  • Register indirect: MOV A, M
  • Implied: CMA, HLT

Flags

  • S — Sign (MSB of result).
  • Z — Zero (1 if result 0).
  • AC — Auxiliary Carry (bit 3→4).
  • P — Parity (1 if even # of 1s).
  • CY — Carry/borrow out of MSB.

Memory & I/O

  • 64 KB (0000H–FFFFH).
  • Memory-mapped and I/O-mapped.
  • IN / OUT ports — 256 ports.
  • Stack grows downward from SP.
  • PUSH/POP use SP automatically.

Viva Questions & Answers

  1. Q: Size of 8085 data bus?
    A: 8 bits.
  2. Q: How much memory can 8085 address?
    A: 64 KB.
  3. Q: Which register is the accumulator?
    A: Register A.
  4. Q: What does Z flag indicate?
    A: Result is zero.
  5. Q: Role of HL pair?
    A: Memory pointer (M = [HL]).
  6. Q: MOV vs MVI?
    A: MOV is register-to-register; MVI is immediate.
  7. Q: What is SP?
    A: 16-bit stack pointer.
  8. Q: JMP vs CALL?
    A: CALL pushes return address; JMP doesn't.
  9. Q: What flags does CMP affect?
    A: All flags, as if subtraction.
  10. Q: What does HLT do?
    A: Halts the processor.
  11. Q: Purpose of AC flag?
    A: BCD arithmetic (bit 3→4 carry).
  12. Q: INR vs INX?
    A: INR = 8-bit; INX = 16-bit pair.

GNUSim8085: Installation & Usage

  1. Download GNUSim8085 from SourceForge or your Linux distro's package manager.
  2. Ubuntu/Debian: sudo apt install gnusim8085.
  3. Windows: download the installer and follow the wizard.
  4. Launch GNUSim8085. The editor opens with a sample program.
  5. Type your assembly. Use ; comments freely.
  6. Press Assemble (F9).
  7. Press Step (F7) to execute one instruction.
  8. Watch registers, flags and memory update live.
  9. Press Run (F5) to execute until HLT.
  10. Press Reset to clear state.
  11. GNUSim8085 supports the full 8085 set; this site supports a documented subset.
